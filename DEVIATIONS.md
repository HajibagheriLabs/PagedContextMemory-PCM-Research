might invalidate a result) are recorded here as well.

| D-010 | 2026-11-14 | A1, T3 | T3: finite logits, same token count and position layout as the equivalent text prompt | "Position layout" is checked numerically: layer-0 keys and values of the stitched cache must equal those of the text prompt at every position, and the first page must agree at every layer, both within 1e-3 relative to the largest magnitude. "48K" is 49,152 tokens, "16K" is 16,384, "100K" is 100,000 | The specification does not define the positions scored. Scoring the same tokens makes the conditions comparable | None |
| D-012 | 2026-11-14 | A1, T5 | Assert peak VRAM < 12 GiB | The assertion is on PyTorch's peak allocated memory. With it, reserved stays within 0.8 GiB of allocated | None |
